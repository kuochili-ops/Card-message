白六立體訊息卡片 (Pop-Up Message Card Simulator)
一款基於 WebGL 與 Three.js 開發的 3D 立體卡片互動模擬器。本專案以精準的物理幾何運動學呈現 V-Fold 彈出式機構，讓使用者能輕鬆創建、預覽、錄製並分享帶有動態訊息的精美 3D 立體賀卡。
👉 線上展示專案 (Live Demo)：https://kuochili-ops.github.io/Card-message/
🌟 核心特色 (Features)
1. 三維物理 V-Fold 立體機構擬真
￼ 實現真實紙藝 V-Fold 機構摺疊過程，具備動態角度開闔與透視視覺感。
￼ 字卡底部零間隙貼合內頁平面，嚴格保持高質感的物理結構比例。
2. 多行動態訊息輪播
￼ 支援輸入多行訊息文字，每一次開闔卡片均會自動切換至下一行內容。
￼ 具備自動伸縮自適應字寬技術，文字過長時僅壓縮寬度不縮放高度，確保視覺美觀不超出卡片極限。
3. 高質感手作內頁紋理
￼ 內建高質感幾何點陣（Polka Dot Grid）底紋與手作虛線畫框。
￼ 右下角精緻圓形白六「早安 / Good Morning」印章標章設計。
4. 🎥 一鍵自動錄影存檔 (MediaRecorder)
￼ 點擊右上角「錄影」按鈕，系統會自動播放並錄製所有訊息行的展頁與換頁過程。
￼ 展頁時每行訊息自動精準停留 4 秒鐘，方便觀賞與分享，錄製完畢後自動匯出高畫質 ⁠.webm⁠ 影片檔。
5. 🔗 URL 訊息設定複製與分享
￼ 點擊右上角「分享」按鈕，即可將您輸入的多行訊息與客製配色（底色、文字色、字卡色）打包為網址參數並複製。
￼ 收件者打開連結時即可原汁原味地重現您製作的立體卡片。
🛠️ 技術架構 (Tech Stack)
￼ 前端核心：原生 HTML5 / CSS3 / JavaScript (ES6+)
￼ 3D 渲染引擎：Three.js (r128)
￼ 控制與視角：Three.js ⁠OrbitControls⁠
￼ 動態貼圖與字體渲染：HTML5 Canvas 2D API
￼ 畫面錄製：HTML5 ⁠MediaRecorder⁠ API (⁠canvas.captureStream⁠)

📖 使用說明 (User Guide)
1. 輸入與編輯訊息：
￼ 展開「彈出訊息」設定介面，在文字區域輸入多行文字（每行代表一次卡片開啟時顯示的句子）。
2. 客製化配色：
￼ 展開「配色設定」介面，自由調整卡片底色、文字顏色與字卡底色。
3. 互動點擊：
￼ 點擊 3D 卡片任意處，可手動開闔卡片。
￼ 停止操作 6 秒後，系統會自動嘗試進行下一行訊息的開啟演示。
4. 錄影與分享：
￼ 錄影：點擊右上角 ⁠🎥 錄影⁠，將自動輪播錄製所有文字，每行停留 4 秒，完成後自動下載 ⁠.webm⁠ 影片。
￼ 分享：點擊右上角 ⁠🔗 分享⁠，複製專屬網址發送給好友。
